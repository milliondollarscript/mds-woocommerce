WooCommerce payment provider adapter for Million Dollar Script.

== Description ==

Million Dollar Script WooCommerce Checkout registers WooCommerce as a payment provider for the Million Dollar Script core payments API. It creates WooCommerce orders for Million Dollar Script checkout sources, syncs payment status back to Million Dollar Script, and adds customer Manage actions for linked WooCommerce orders.

== Installation ==

1. Install and configure WooCommerce.
2. Activate Million Dollar Script.
3. Activate Million Dollar Script WooCommerce Checkout.
4. Open Million Dollar Script -> Setup.
5. Choose WooCommerce as the Payment Provider.
